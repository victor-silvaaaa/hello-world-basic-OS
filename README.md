# hello-world-basic-OS
a minimal hello world OS made in assembly.
I used the NASM x86 32-bit assembly language to write our assembly code for a 32-bit, x86 processor. we will use QEMU for emulating directly on Makefile.

the bootloader is from the github repository:
https://github.com/lukearend/x86-bootloader/tree/master

You can see the original bootloader's README in https://github.com/lukearend/x86-bootloader/blob/master/README.md

theres a bonus expansive keyboard input driver too.
